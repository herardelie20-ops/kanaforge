# KanaForge — contours chrome monochromes

Tous les PNG de ce dossier ont un intérieur et un extérieur transparents. Ils
servent de contours décoratifs, à placer au-dessus d'un fond noir sans couvrir
le contenu.

| Fichier | Usage prévu |
| --- | --- |
| `window-frame-wide-top-left.png` | Fenêtre large, variation avec coulée en haut à gauche |
| `window-frame-vertical-right-fold.png` | Inspecteur et panneau latéral vertical |
| `window-frame-square-bottom-left.png` | Carte compacte et tuile carrée |
| `button-frame-primary-long.png` | Action principale longue |
| `button-frame-secondary-compact.png` | Action secondaire compacte |
| `button-frame-icon-square.png` | Bouton outil ou icône carré |

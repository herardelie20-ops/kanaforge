# Cadres chrome à griffes

20 contours PNG monochromes, à centre et extérieur transparents. Ils sont pensés pour se placer **autour** d’un composant (`::after` avec `inset` négatif), jamais sur son contenu.

## Répartition

- `01`–`04` : fenêtres larges, verticales et cartes.
- `05`–`11` : boutons, onglet, menu déroulant et puce métrique.
- `12`–`13` : rails de navigation et réglages.
- `14`–`18` : modale, champ, barre média et panneaux spécialisés.
- `19`–`20` : badge circulaire et footer / timeline.

Chaque asset reprend la même matière : chrome noir et argent, liquide poli, détails organiques en griffes, crochets ou pointes. Les centres ont été vérifiés transparents afin de conserver le fond noir et le texte de l’interface visibles.

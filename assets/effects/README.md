# Effets et éclairages libres

- **ImageTracerJS** — vectorisation bitmap vers contours SVG, licence Unlicense.
- **Three.js** — rendu, extrusion et éclairage temps réel, licence MIT.
- **Poly Haven** — textures et environnements de studio, licence CC0.

Les contrôles ajoutés dans l’interface exploitent ces composants libres : couleur, réflexion métal, lueur, lumière principale, lumière de contour et exposition.
